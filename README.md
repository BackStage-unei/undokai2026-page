## ⚠️ 公開（GASデプロイ）前に必ずやること

現在のHTMLには **キャスト向けの一時セクション「PV音声収録のお願い」** が含まれています（Googleフォーム・提出先メールアドレス入り）。一般公開する前に必ず削除してください。

1. HTML内の `<!-- CAST-ONLY:PV-VOICE START ... -->` 〜 `<!-- CAST-ONLY:PV-VOICE END -->` ブロックを**2箇所とも**（ヒーローのナビリンク＋本体セクション）丸ごと削除
2. `tests/test_event_page.py` の `CAST_ONLY_PV_EXPECTED = True` を `False` に変更
3. テストを実行して全PASSを確認（False時は「削除漏れ」を検知します）

## 編集ルール

- base64の画像データ行には触れない（差し替えはツール経由で）
- 絵文字・`<script>`・外部リソース読み込みは禁止（テストが検知します）
- 掲載禁止: 予算・報酬額・内部の必要売上・チーム分けアルゴリズム・運営担当者名・未確定の具体数値
- マスター編集は暮林側（work_ob vault）の運用フローで行い、本リポジトリへ同期します。直接編集した場合はテストを回してからpushしてください
