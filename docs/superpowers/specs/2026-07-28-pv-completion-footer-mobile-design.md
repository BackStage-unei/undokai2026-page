# PV音声収録チェック・フッター・脱落ルール修正仕様

## 目的

参加キャストがPV用セリフの収録状況を把握しやすくし、ページ末尾の注意事項を最新の案内へ更新する。また、狭いスマートフォン画面で脱落条件が文字単位に崩れる問題を解消する。

## 変更内容

### 1. PV用セリフの完了チェック

- セリフ1〜5の各カードに「完了」チェックボックスを1つずつ設置する。
- チェックを付けると、該当カード全体を淡い緑色にし、完了状態がひと目で分かるようにする。
- セリフ4・5はチーム切り替えの外側にあるカード単位で管理し、チームごとに重複したチェック状態は持たせない。
- チェック状態はブラウザのローカルストレージへ保存し、同じブラウザでページを再読み込みしても維持する。
- チェックボックスはキーボード操作とスクリーンリーダーでも利用できる標準の`input[type="checkbox"]`を使用する。

### 2. フッター注意書き

次の2文へ置き換える。

> 本ページは参加キャスト向けの案内です。外部への共有はしないでください。
>
> 一部調整中の項目がありますので、最新情報は運営からの連絡をご確認ください。適宜本ページも更新します。

### 3. 脱落ルールのスマートフォン表示

- 「10pt未満 → 脱落」と「（中間発表に不参加）」を意味のまとまりとして扱う。
- 十分な横幅では1行表示を維持する。
- 狭い横幅では上記2つのまとまりの間だけで折り返し、文字単位の不自然な改行を防ぐ。
- 既存の赤いピル型デザインは維持する。

## 実装方針

- 既存のセリフ4・5生成処理が完了した後、5枚のセリフカードへ共通処理でチェックUIを追加する。
- 保存キーはページ専用の固定キーとし、セリフ番号ごとの真偽値だけを保存する。
- ローカルストレージが利用できない環境でもチェック操作自体は継続できるよう、保存・読込時の例外は画面を止めずに扱う。
- 3つのHTML成果物へ同じ内容を同期する。

## 確認範囲

- セリフ1〜5にチェック欄が1つずつ表示されること。
- チェック時に対象カードのみ緑色になり、解除時に元へ戻ること。
- 再読み込み後もチェック状態が復元されること。
- フッターが指定の2文になっていること。
- 320px幅で脱落条件が文字単位に崩れないこと。
- 全テストは実行せず、今回の変更に関係するDOM・表示・操作のみ確認する。
