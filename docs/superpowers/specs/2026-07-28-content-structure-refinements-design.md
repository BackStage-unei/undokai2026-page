# キャストガイド情報整理デザイン

## 目的

モバイル閲覧時に、重要情報へ先に到達でき、長いチーム情報やPV音声情報は必要な箇所だけ展開できるようにする。

## 合意済みの変更

1. デイリーミッション冒頭の8/20・8/23集計カードを削除する。セクション末尾で「中間発表・最終結果発表の都合により、8/20は0:00〜20:00、8/23は0:00〜21:00で集計します。」と1回だけ案内する。
2. スケジュール内の8/20・8/23集計カードと、その直下の補足文を削除する。日別集計タイムテーブルの4日目に「20:00締め」を表示する。
3. スケジュール末尾の「集計の締め時間は、配信スケジュールに合わせて変わります。」を削除する。
4. 特典はカード冒頭で「優勝：描き下ろし集合SDイラスト」「準優勝：既存立ち絵を使用した集合立ち絵ポスター」を先に示し、その後に店舗掲出・ブースPOP・Discord詳細リンクを置く。
5. PVセリフ4・5はセリフ1〜3と同じカード表現で別々に表示する。各カード内に6チームの切替ボタンを置き、選択したチームのセリフ、ファイル名、9名の画像を表示する。
6. 録音方法は「録音のコツ → Route A → Route B」の順にする。提出フォームと説明はRoute Aカード内へ移し、独立した提出方法欄は削除する。
7. チーム発表は6組を個別のネイティブトグルにし、初期状態をすべて閉じる。組名を押すと9名のメンバーを表示する。

## 実装方針

- 既存のチーム画像・セリフ・ファイル名を正本として維持し、JavaScriptで表示構造だけを強化する。
- チーム発表は既存の `.team-card` をネイティブの `details` / `summary` に変換する。
- PVチーム別情報は既存の6チームカードからセリフ4・5の2カードを生成する。ボタンは通常の `button` を使用し、選択状態を `aria-selected` と `hidden` で同期する。
- JavaScriptが動作しない場合は、現在の6チーム一覧をフォールバックとして残す。
- 既存の配色、角丸、影、画像、文章内容は、今回の指定箇所以外では変更しない。

## 確認範囲

全テストは実行しない。390px幅のブラウザで、変更した7項目の文言、表示順、開閉、チーム切替、横方向のはみ出しだけを確認する。
