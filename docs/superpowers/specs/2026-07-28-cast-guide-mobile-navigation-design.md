# 大運動会2026 キャスト向け案内ページ改修 設計仕様

## 目的

大運動会2026の参加キャストが、モバイル端末から必要な情報へすばやく移動し、イベントルール、集計時間、賞品、PV音声収録、問い合わせ先を誤解なく確認できるページへ改修する。

既存のイベントルールや数値は変更しない。閲覧者を一般ユーザーではなく参加キャストとして統一し、ユーザー向けLPに見える呼びかけだけをキャスト向けの説明へ修正する。

## 対象ファイル

- `イベント概要_大運動会2026.html`: ページ本体
- `index.html`: GitHub Pages公開用ファイル
- `undo-kai.html`: 現在ページ本体と同一内容の複製
- `tests/test_event_page.py`: ページ構造・文言・リンク・メニュー挙動のセルフチェック
- `README.md`: GitHub PagesとJavaScript利用を含む運用説明

3つのHTMLは改修後も同一内容を維持する。

## 1. モバイルナビゲーション

### 構成

既存の上部バーを画面上端に固定し、BackStageロゴとハンバーガーボタンを配置する。ハンバーガーボタンから、ページ内の主要セクションへ移動できるネイティブの `<dialog>` メニューを開く。

メニュー項目は次の順序とする。

1. イベント概要
2. チーム発表
3. デイリーミッション
4. ポイントのしくみ
5. 中間発表クイズ
6. 脱落ルール
7. スケジュール
8. 特典
9. PV音声収録
10. FAQ
11. お問い合わせ

既存のヒーロー内ナビゲーションはデスクトップ用の補助導線として維持し、モバイルでは固定メニューとの重複を避けるため非表示にする。

### 操作

- ハンバーガーボタンで開閉する。
- メニュー項目を選ぶと該当セクションへスクロールし、メニューを閉じる。
- Escapeキー、メニュー外側のタップ、閉じるボタンで閉じる。
- メニュー表示中は本文の背景スクロールを止める。
- 開いた直後は閉じるボタンへフォーカスを移す。
- 閉じた後はハンバーガーボタンへフォーカスを戻す。
- ネイティブのモーダルダイアログによって、メニュー内でTab移動したときのフォーカスをメニュー内に保つ。
- `aria-expanded`、`aria-controls`、ダイアログの名前を設定し、キーボードとスクリーンリーダーから操作できるようにする。
- メニュー開閉には外部ライブラリを使用せず、HTML内の小さなインラインJavaScriptを使用する。
- GitHub Pagesでそのまま動作する構成とする。
- 固定バーは端末のセーフエリアを考慮する。
- 開閉アニメーションを付ける場合は200ms以内の `transform` と `opacity` のみを使い、`prefers-reduced-motion` を尊重する。

## 3. 集計期間の明確化

デイリーミッション冒頭とスケジュールの日別集計表の前に、例外となる2日を強調表示する。

- 8/20(木): 集計期間 0:00〜20:00
- 8/23(日・最終日): 集計期間 0:00〜21:00

通常日の集計は0:00〜23:59であることも併記する。デイリーミッション末尾の「毎日0時にリセット」は維持しつつ、8/20と8/23は締め時間が異なる旨を同じ注意枠内に表示する。

スケジュールのタイムラインにも次の内容を明記する。

- 8/20: 20:00集計締め、21:00中間発表クイズ配信
- 8/23: 21:00集計締め、21:00最終結果発表

既存の日別集計グラフとアクセシブルネームは維持する。

## 4. 賞品の整理

特典セクションの冒頭に「賞品は優勝・準優勝の2種類」と明記し、内容を2枚のカードに分ける。

### 優勝賞品

- チームメンバー全員の描き下ろし集合SDイラストを制作
- 集合SDイラストを自遊空間の店舗にパネル設置
- 店内ブース席にチームのブースPOPを掲出

### 準優勝賞品

- 既存立ち絵を使用したチームの集合立ち絵ポスターを制作
- ブースPOPとして自遊空間の店内ブース席に掲出

掲出店舗、時期、約1ヶ月の予定、詳細調整中という既存情報は維持する。

### 導入文

> もし参加可能な方がいらっしゃいましたら、下記セリフを期限までにご提出いただけると嬉しいです！

> 参加は強制ではありません。お時間に余裕のある方は、ぜひご協力をお願いします！

提出期限は次のように表示する。

- 8/1(土) 13:00ごろ
- この日の13:00ごろから本格的に作業を始める予定です。

### セリフ数

収録対象は「全員共通3つ＋自分のチーム2つ＝計5つ」とする。応援の声は任意の追加枠ではなく、全員共通の3つ目として表示する。

1. 「BackStage大運動会！」
2. 「よーい、どん！」
3. 応援の声
4. 自分の組名
5. 自分のチームの掛け声

### ファイル名

各セリフカードに、そのセリフに対応するファイル名を直接表示する。テイク番号は `01` と `02` の2例を表示する。

共通セリフの命名規則:

- タイトルコール: `{TeamColor}_{CastName}_TitleCall01_ORG.wav`、`{TeamColor}_{CastName}_TitleCall02_ORG.wav`
- スタート: `{TeamColor}_{CastName}_Start01_ORG.wav`、`{TeamColor}_{CastName}_Start02_ORG.wav`
- 応援: `{TeamColor}_{CastName}_Cheering01_ORG.wav`、`{TeamColor}_{CastName}_Cheering02_ORG.wav`

### チーム画像

各チームのセリフカードに、そのチームのキャスト9名の既存画像を3×3の小さい画像として表示する。

- チーム発表に使っている画像と同じ画像・同じ順序を使用する。
- 画像データを新規追加しない。
- 各画像の代替テキストはキャスト名とする。
- 小さい画像でも顔が判別できるよう `object-fit: cover` と既存のチームカラー枠を使用する。

### 録音方法

録音方法の2ルート、番号付き手順、ファイル名、宛先、件名、録音のコツは左揃えにする。セクション全体の見出しは既存デザインに合わせて中央揃えを維持する。

内容はGoogleドキュメントを基準に次を維持する。

- 慣れている方: wav、できれば24bit / 48kHz、ギガファイル便などへアップロード、GoogleフォームへURLを提出
- よくわからない方: iPhoneのボイスメモで録音し、メール送付
- 宛先: `h_sawa@virtualidol.info`
- 件名: `大運動会セリフ_キャスト名_◯組`
- 反響の少ない環境、マイクからこぶし1つ分離す、使用可能なテイクを複数提出

提出フォームURLは既存の `https://forms.gle/SMoTKsQ16n4mtEuE9` を維持する。
