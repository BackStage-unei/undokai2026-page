# 賞品欄・優勝チーム2枠表示

## 目的

元のmainの賞品欄の構成を踏襲し、優勝賞品の内容を用途別の2つの金色カードで表示する。

## 表示構成

1. 上段に金色の「優勝チーム」カードを置き、次の文章だけを表示する。
   - 優勝チームには、チームメンバー全員の描き下ろし「集合SDイラスト」を制作します。
2. 続けて、自遊空間への掲出予定と掲出期間の文章を表示する。
3. その下に既存の金色の「優勝チーム」カードを残し、店舗へのパネル設置とブースPOP掲出を表示する。
4. 続けて既存の「準優勝チーム」カードを表示する。
5. Discordの詳細リンクと注記は現在の位置に残す。

## 実装範囲

- 賞品欄のHTML構造を変更する。
- 既存の金色カードのスタイルを再利用する。
- ほかのセクション、文章、トグルの動作は変更しない。

## 確認

- モバイル幅で「優勝チーム」カードが2つ表示される。
- 上段カードには集合SDイラスト制作の文章だけが入る。
- 下段カードにはパネル設置とブースPOP掲出だけが入る。
- 横方向のはみ出しがない。
