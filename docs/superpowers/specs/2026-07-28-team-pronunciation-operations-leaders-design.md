# 組名コール読み仮名・運営リーダー表示 設計

## 目的

PV音声収録時に組名を迷わず読めるようにし、参加キャストが自分のチームの運営リーダーをすぐ確認できるようにする。

## 変更内容

### 組名コールの読み仮名

PV音声収録の「セリフ4・組名コール」にある6チームの組名へ、HTMLのルビ表記を追加する。引用符と感嘆符は現在のまま維持し、チーム見出し、掛け声、ファイル名は変更しない。

| 表記 | 読み仮名 |
| --- | --- |
| 赤組 | あかぐみ |
| 青組 | あおぐみ |
| 黄組 | きぐみ |
| 緑組 | みどりぐみ |
| 橙組 | おれんじぐみ |
| 紫組 | むらさきぐみ |

### 運営リーダー

「チーム発表」にある各チームの見出し直下へ、補助情報として `運営リーダー：氏名` を表示する。PV音声収録のチーム別セリフ欄には重複表示しない。

| チーム | 運営リーダー |
| --- | --- |
| 赤組 | 小松 |
| 青組 | 木村 |
| 黄組 | 代表田中 |
| 緑組 | 室井 |
| 橙組 | 野崎 |
| 紫組 | 田中烈 |

## 表示方針

- 既存の配色、カード構造、開閉動作は維持する。
- 運営リーダーはチーム名より控えめな文字サイズのラベルとし、メンバー一覧を圧迫しない。
- スマートフォンでもチーム名と運営リーダー名が不自然に分断されない配置にする。
- 3つのHTML成果物は同じ内容に揃える。

## 確認方法

- 6つの組名コールに指定された読み仮名が存在することを、対象を限定した自動確認で検証する。
- 「チーム発表」に6名の運営リーダーが正しいチーム対応で存在することを検証する。
- PVチーム別セリフ欄には運営リーダー表記が追加されていないことを確認する。
- 全テストは実行せず、今回の変更に関係する確認だけを行う。
