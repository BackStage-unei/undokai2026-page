# 開いたトグルの外枠調整 — デザイン仕様

## 目的

モバイルでトグルを開いた直後、見出しの青い枠線とフォーカスアウトラインが重なり、太い二重の外枠に見える状態を解消する。

## 承認された方針

- 閉じたトグルの枠線、配色、角丸は維持する。
- 開いたトグル見出しでは外周の枠線を透明にする。
- 開いた見出しの背景色、文字色、「−」アイコンは現状を維持する。
- キーボード操作に必要なフォーカス表示は消さず、見出しの内側へ表示する。
- 逆配色セクションでも同じ挙動とし、既存の配色を維持する。
- レイアウト、余白、トグルの開閉処理、本文には変更を加えない。

## CSS契約

- `.section-toggle[open] > .section-toggle-summary` は透明なボーダーを使用する。
- `.section-toggle-summary:focus-visible` は十分なコントラストを持つ3pxのアウトラインを、負の `outline-offset` で内側へ配置する。
- フォーカス表示は明背景・暗背景ともに視認できる既存色を使用する。

## テスト

1. 修正前のCSSに対し、開いた見出しの枠線が透明でないため失敗する回帰テストを追加する。
2. フォーカスアウトラインが3pxで、内側へ配置されていることを検証する。
3. 3つのHTMLが同一内容であることを検証する。
4. 既存の全テストを実行する。
5. 390px表示でトグルを開き、二重の外枠が消え、横方向のはみ出しがないことをブラウザーで確認する。
